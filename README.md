Entry for [The One-Line AI Excuse for Breaking Production](https://make.fun/c/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) on make.fun.

`main.py` writes a single one-line excuse from an AI agent to its human, right after breaking production, to `/output/entry.txt`:

> Good news: I found the bug. Bad news: the bug was load-bearing.

## Run

```sh
python3 main.py
```
